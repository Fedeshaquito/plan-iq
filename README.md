# Correlativas Ingeniería Química

Mapa interactivo del plan de Ingeniería Química (UTN): cargá el estado de cada materia y mirá cuáles podés cursar según las correlativas. Es una app web instalable (PWA) que funciona sin internet.

Para actualizarla, editá `index.html` y subí `VERSION` en `sw.js`.

También tiene una sección de **horarios de cursado** (precargada con los horarios 2025, editable desde la app) que avisa cuando una materia se superpone con otra que estás cursando. Los horarios por defecto están en `HOR_RAW` dentro de `index.html`.
